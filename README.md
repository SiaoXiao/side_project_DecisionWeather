## 📄 Description

DecisionWeather is a lightweight weather decision helper built with Vue 3 and Vite. It provides quick city search, current conditions, and a simple action-oriented recommendation card, with i18n support and a clean responsive UI.

**Key Features:**
- Vue 3: Reactive, composable UI with Composition API
- Vite: Fast dev server and optimized builds
- TailwindCSS: Utility-first styling for responsive layouts
- i18n: zh-TW and en-US language support
- No API key required: Weather data from Open-Meteo

## 🚀 Features

- Geolocation-based weather for current location
- City search with keyboard navigation
- Action advice based on temperature, rain, and UV
- Hourly forecast for the next 6 hours
- i18n support (zh-TW, en-US)

## 📦 Setup & Development Server

1. Installation: Clone the repository and run `npm install` to install dependencies.
2. Development: Run `npm run dev` to start the development server with hot module replacement.
3. Open `http://localhost:5173/` in your browser.
